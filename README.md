# mdwnstudio.github.io

Serves `/.well-known/assetlinks.json` at the domain root so Android trusts the
Siraj app (package `io.github.mdwnstudio.siraj`) to open
https://mdwnstudio.github.io/Siraj/ full screen, without a browser bar.

The app itself lives in [mdwnstudio/Siraj](https://github.com/mdwnstudio/Siraj).
